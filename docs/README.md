# Sariya App Docs

Reference docs for keeping the app consistent as it grows. Read these before adding a new screen, component, or style.

- [design.md](./design.md) — colors, typography, spacing, and component patterns to reuse.
- [structure.md](./structure.md) — folder layout and where new files belong.
- [navigation.md](./navigation.md) — every route in the app, the tab bar, and linking rules.
- [conventions.md](./conventions.md) — coding conventions (imports, naming, state) and known inconsistencies to avoid copying.

**Stack:** Expo SDK 54, Expo Router 6 (file-based routing), React Native 0.81, NativeWind 4 (Tailwind for RN), React Navigation bottom-tabs 7, TypeScript.
